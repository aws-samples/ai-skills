# `video`

One skill that turns an idea into a narrated 1920×1080 MP4. It runs when a person invokes its slash
command or asks for a video in the session, never on an agent's own initiative, because voicing a
video spends money.

| Skill | What it does |
|---|---|
| [`ai-video`](./ai-video/) | writes a storyboard, an HTML deck, live demos of a web app and animated diagrams, voices the narration, and renders an MP4 from a bundle a person can edit and render again |

The domain's shared references live at `skills/video/.ai-video-reference/` (`project-context.md`,
`manifest-update.md`), byte-identical to the research and document domains' copies, because a video
bundle is a working folder like theirs. `ai-video` carries its own copy of each in its `references/`
folder.
